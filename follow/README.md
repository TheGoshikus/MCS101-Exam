# Follow: лендинг для сбора заявок с записью пути пользователя

Одностраничный лендинг с формой заявки. Встроенный трекер записывает, что посетитель делает на странице.
Каждую запись потом можно посмотреть как видео в плеере `replay.html`.

## Что записывается

| Событие | Что видно в плеере |
|---|---|
| Движение мыши | курсор и затухающий след |
| Касания и свайпы пальцем | кружок под пальцем, след свайпа, в журнале «Свайп вверх/вниз, N px за M мс» |
| Прокрутка (колесо, палец, клавиши) | страница прокручивается так же, как у посетителя |
| Клики и тапы по всем кнопкам, ссылкам, полям и вопросам FAQ | красная вспышка, подсветка элемента, текст кнопки |
| Форма: фокус, ввод, галочка согласия | поля заполняются точками по числу введённых символов |
| Цели | начал заполнять форму, ошибка в форме, заявка отправлена, прокрутка 25/50/75/100% |
| Уход со вкладки и возврат, изменение размера окна | отметки в журнале |

**Сами значения полей (имя, телефон, комментарий) трекер не записывает**, только сколько символов введено.
Контакты приходят отдельно, в заявке. К заявке прикреплён `sid` записи, поэтому в плеере у каждой заявки
можно посмотреть путь этого клиента (фильтр «Только с заявкой»).

## Файлы

```
follow/
  index.html        лендинг
  replay.html       плеер записей (админка)
  css/style.css     стили лендинга
  css/replay.css    стили плеера
  js/config.js      настройки: адрес сервера, Яндекс Метрика, согласие на cookies
  js/tracker.js     трекер (подключён в <head> лендинга)
  js/main.js        форма, маска телефона, цели, анимации
  js/replay.js      плеер
  server/server.js  сервер: раздаёт страницы, принимает записи и заявки (Node.js 18+, без зависимостей)
  data/             сюда сервер складывает данные (не коммитится)
```

## Где опубликовано

- Лендинг: https://follow.com.ai (и `www.follow.com.ai`), запасной адрес https://follow-3xn.pages.dev
- Записи и заявки: https://follow.com.ai/replay.html, вход по `ADMIN_TOKEN`
- Хостинг: Cloudflare Pages, проект `follow`. API — `functions/api/[[path]].js` (Pages Functions),
  данные — база Cloudflare D1 `follow-db` (таблицы `sessions`, `chunks`, `leads`).
- `ADMIN_TOKEN` хранится как секрет проекта Pages. Сменить:
  `npx wrangler pages secret put ADMIN_TOKEN --project-name follow`, затем `./deploy.sh`.

Обновить сайт после правок:

```bash
cd follow
export CLOUDFLARE_API_TOKEN=... CLOUDFLARE_ACCOUNT_ID=...
./deploy.sh
```

Выгрузить заявки из базы:

```bash
npx wrangler d1 execute follow-db --remote --command "SELECT data FROM leads ORDER BY id DESC"
```

## Запуск на своём сервере (вместо Cloudflare)

```bash
cd follow
ADMIN_TOKEN=придумайте-пароль PORT=8080 node server/server.js
```

- Лендинг: http://localhost:8080/
- Записи: http://localhost:8080/replay.html, вход по `ADMIN_TOKEN`

Данные лежат в `follow/data/`: записи в `sessions/<sid>.jsonl`, заявки в `leads.jsonl`.
Другую папку можно задать через `DATA_DIR=/путь`.

На хостинге сервер запускается так же, за nginx или любым другим прокси с HTTPS (VPS, Render, Railway и т. п.).

### Без сервера

Если открыть `index.html` прямо с диска, записи и заявки сохраняются в localStorage этого браузера.
`replay.html` из той же папки их покажет. Это удобно, чтобы проверить работу трекера.

### Лендинг на GitHub Pages, сервер отдельно

В `js/config.js` укажите адрес сервера: `apiBase: 'https://analytics.example.com'`.
Трекер и форма шлют данные как `text/plain`, поэтому CORS preflight не нужен.

## Яндекс Метрика (Вебвизор)

Метрика подключается параллельно со своим трекером. Укажите номер счётчика в `js/config.js`:

```js
metrikaId: 12345678,
```

Тогда включаются Вебвизор (запись сессий в интерфейсе Метрики), карта кликов, карта скроллинга и цели:

- `click`: любой клик по кнопке или ссылке (в параметре `element` указано, по какой);
- `click_<имя>`: клик по конкретной кнопке, например `click_cta_hero`, `click_lead_submit`, `click_cta_sticky_mobile`;
- `form_start`, `form_invalid`, `lead_submit`, `lead_error`;
- `scroll_25`, `scroll_50`, `scroll_75`, `scroll_100`.

В Метрике цели заводятся как «JavaScript-событие» с этими идентификаторами. В Вебвизоре в параметрах визита
есть `follow_sid`, по нему визит можно сопоставить с записью в своём плеере.

## Как добавить кнопку в аналитику

Клики по любым `a`, `button`, `input`, `label`, `summary` записываются автоматически.
Чтобы кнопка была подписана понятным именем в журнале и в целях Метрики, добавьте ей `data-track`:

```html
<a href="#lead" class="btn" data-track="cta_price">Узнать цену</a>
```

Свою цель из JS можно отправить так: `followTrack.goal('video_play')`.

## Плеер

- Список записей: дата, устройство, размер экрана, число кликов или касаний, источник (utm/referrer), отметка о заявке.
- Фильтры: с заявкой, мобильные, десктоп.
- Скорость 1×–8×, «пропускать паузы», перемотка по таймлайну. На таймлайне цветами отмечены клики, касания, цели и форма.
- «Путь пользователя»: журнал шагов. Клик по шагу перематывает к этому моменту.
- Клавиши: пробел — пауза, ← / → — на 5 секунд назад или вперёд.
- Можно открыть файл записи `.jsonl` из `data/sessions/`, например скачанный с сервера.

## Персональные данные

- В форме есть обязательная галочка согласия на обработку персональных данных. Рядом стоит добавить ссылку
  на вашу политику конфиденциальности.
- Плашка про cookies информационная. Если запись нужно начинать только после согласия,
  поставьте `requireConsent: true` в `js/config.js`.
- Всё, что лежит в `data/`, — персональные данные посетителей. Держите `ADMIN_TOKEN` в секрете и не коммитьте `data/`.

## Тексты

Тексты лендинга (заголовок, преимущества, шаги, FAQ, цифры в первом экране) — заглушки. Замените их
в `index.html` на реальные данные о продукте.
