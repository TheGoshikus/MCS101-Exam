# FOLLOW — лендинг «Ранний доступ»

Вёрстка по макету `FOLLOW Landing.dc.html` из Claude Design (артборды 5a — mobile 390, 5b — desktop 1440)
и ТЗ `FOLLOW_TZ_landing.pdf`. Mobile-first, с 1024 px — десктопная раскладка.

- Тестовый адрес (новый дизайн): https://preview.follow-3xn.pages.dev
- Боевой домен: https://follow.com.ai
- Записи сессий и заявки: `/replay.html`, вход по `ADMIN_TOKEN`

## Форма заявки

1. **Шаг 1** — email и согласия. Кнопка неактивна, пока не отмечены «Согласен на обработку ПД» и «Мне есть 18 лет».
   Заявка сохраняется сразу на этом шаге. Повторный email обновляет первую заявку, а не создаёт вторую.
2. **Анкета** — 5 вопросов из ТЗ, каждый можно пропустить. Ответ сохраняется сразу после каждого вопроса.
3. **«Вы в списке»** — место в очереди (реальный порядковый номер заявки) и реферальная ссылка `?ref=код`
   с кнопками Telegram / WhatsApp / VK / «Скопировать».

В заявке сохраняются: email, согласия с датой и временем, отмеченные карточки «Узнаёте себя?», UTM-метки,
реф-код пригласившего, свой реф-код, вариант A/B, ClientID Метрики, источник, ответы анкеты, id записи сессии.

Защита: ловушка для ботов (скрытое поле), не больше 10 заявок с одного IP в час, блок одноразовых email,
проверка на сервере.

Выгрузка заявок для Excel (UTF-8 с BOM): `/api/leads.csv?token=ADMIN_TOKEN`.

## Аналитика

Яндекс Метрика (Вебвизор, карта кликов) и собственная запись сессий включаются **только после «Принять»**
в cookie-баннере. «Только необходимые» — ничего не пишется. Номер счётчика — `metrikaId` в `js/config.js`.

События (уходят и в Метрику как цели с параметрами, и в запись сессии):

| Событие | Параметры | Где |
|---|---|---|
| `cta_click` | `block` (1, 2, sticky), `placement` | кнопки «Ранний доступ» / «Хочу ранний доступ» |
| `card_select` | `card_id` 0–4, `state` on/off | карточки «Узнаёте себя?» |
| `form_step1_submit` | `cards` | заявка отправлена |
| `form_q1` … `form_q5` | `status` answered/skipped | анкета |
| `form_complete` | — | анкета пройдена |
| `share_click` | `channel` telegram/whatsapp/vk/copy | экран «Вы в списке» |
| `nav_click`, `chip_click`, `tab_switch`, `tone_select`, `faq_open`, `scroll_depth` | см. код | доп. события — согласовать |

`email_confirmed` отправляется с сервера после подтверждения почты — появится вместе с рассылкой писем.

## Публикация

```bash
cd follow
export CLOUDFLARE_API_TOKEN=... CLOUDFLARE_ACCOUNT_ID=...
./deploy.sh preview   # тестовый адрес preview.follow-3xn.pages.dev
./deploy.sh           # боевой сайт follow.com.ai
```

Сменить пароль админки: `npx wrangler pages secret put ADMIN_TOKEN --project-name follow` (и `--env preview`).

### Свой сервер (Node.js)

```bash
cd follow
ADMIN_TOKEN=пароль PORT=8080 node server/server.js
```

Данные — в `follow/data/` (`signups.json`, `sessions/*.jsonl`), папка не коммитится.
